# Mood style artwork licences

The Mood style packs bundle unmodified emoji artwork from openly licensed sets (resized only). Jotla's own Classic faces are drawn in code and belong to the app. Per-pack sources:

| Pack folder | Set | Source | Licence |
|---|---|---|---|
| `sticker/`, `sticker-cat/` | Microsoft Fluent Emoji (3D) | github.com/microsoft/fluentui-emoji | MIT |
| `soft/` | Microsoft Fluent Emoji (Color) | github.com/microsoft/fluentui-emoji | MIT |
| `flat/` | Microsoft Fluent Emoji (Flat) | github.com/microsoft/fluentui-emoji | MIT |
| `bubble/`, `bubble-cat/` | Google Noto Emoji | github.com/googlefonts/noto-emoji | Apache 2.0 |
| `bold/` | Twemoji | github.com/jdecked/twemoji | Graphics CC BY 4.0 (copyright Twitter, Inc and other contributors) |
| `outline/` | OpenMoji | openmoji.org · github.com/hfg-gmuend/openmoji | CC BY-SA 4.0 |

Files per pack: `happy`, `ok`, `sad`, `worried`, `angry`, mapped to the app's five moods. Smiley packs use U+1F60A, U+1F610, U+1F641, U+1F61F, U+1F620; cat packs use U+1F638, U+1F431, U+1F63F, U+1F640, U+1F63E.

User-facing attribution lives on the About Jotla page. Downloaded and verified 2026-08-09 (40 files, all HTTP 200, none empty).
